# Destination Galleries

This folder is the only place you need to edit gallery images.

Each destination has its own folder:

- `la-fortuna`
- `papagayo`
- `puerto-viejo`
- `manuel-antonio`
- `tamarindo`
- `san-jose-city`

Current convention per folder:

- `gallery-1`
- `gallery-2`
- `gallery-3`
- `gallery-4`

You can replace these files with better images using the same names and extension.
If you add more images, keep the file inside the same destination folder and the site will load it automatically.

Example:

- `src/assets/destinations/details/la-fortuna/gallery-5.jpg`

Do not edit `public/assets/destinations/details`. That duplicate folder is no longer used.
