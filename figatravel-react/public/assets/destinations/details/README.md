# Destination Galleries

Each destination has its own folder:

- `la-fortuna`
- `papagayo`
- `puerto-viejo`
- `manuel-antonio`
- `tamarindo`
- `san-jose-city`

Current convention per folder:

- `gallery-1`
- `gallery-2`
- `gallery-3`
- `gallery-4`

You can replace these files with better images using the same names and extension.
If you add more images, also add their paths in `src/presentation/data/siteContent.ts` inside each destination `gallery` array.
